# dsh-daily-review（日精进）

给 DeepSeek Harness 的本地日精进存档：原文是普通 Markdown，存在自己的机器上，按活动文件夹分组、按日期翻阅，Agent 可以直接检索原文做复盘。

## 数据在哪里

默认根目录 `~/日精进`（即当前用户主目录下的 `日精进` 文件夹），可在「设置 → 插件 → 日精进」里改。

```
日精进/
  学习/2026-10-25.md          当天第一条
  学习/2026-10-25 2.md        同一天第二条起
  学习/2026-10-25 阶段汇报.md  填了标题时
  .daily-review/folders.json      文件夹元数据 + 每夹模板 + 排序
  .daily-review/backups/<日期>/   写入前备份，保留 10 天
  .daily-review/trash/<时间戳>/   删除的条目，保留 7 天
```

首次启动且目录为空时，会自动创建四个示例文件夹（学习 / 工作 / 生活 / 总结）和一套默认板块模板，都可以随时改名或删除。已存在的数据目录不会被改动。

目录即真源。`.daily-review` 只是缓存与备份，删掉它重启后会按磁盘上的目录和文件重建索引，条目一个不少（模板会回到默认值，因为它就存在 folders.json 里）。

每个 `.md` 的 frontmatter：

```yaml
---
date: 2026-10-25
title: 阶段汇报          # 可空
folder: 学习             # 仅参考，以所在目录为准
sections:                # 这一篇自己的板块清单
  - 今日要点
  - 今日收获
created: 2026-10-25T23:10:00+08:00
updated: 2026-10-26T00:05:00+08:00
---
```

`sections` 缺失时从正文的 `## ` 标题反推。frontmatter 被手改坏也不丢内容：仍按文件名日期读出，并在界面与工具结果里标「格式异常」。

## 界面

侧边栏「日精进」→ 文件夹卡片（色点 / 篇数 / 最近日期 / 本月天数，可拖拽排序）→ 文件夹内按日期倒序的条目 → 阅读态 / 编辑态。

- 新建文件夹必须设置板块模板，至少 1 个板块。
- 新建条目时正文按该夹模板生成骨架，光标停在第一个板块标题之后。
- 编辑态的板块条：拖动排序（正文整体跟随）、双击改名（同步改 `## 标题`）、× 删除（有正文时二次确认，默认只删标题保留正文）、+ 添加板块、从其他文件夹模板载入。
- 单篇的板块改动只影响这一篇，绝不写回文件夹模板，也不影响其他条目。
- 「存为该文件夹模板」把当前结构存成默认值：只影响之后新建的条目。
- 搜索：当前文件夹 / 全部文件夹，输入即搜（250ms 防抖），命中带前后 30 字与高亮。
- 日历：有记录的日期标小圆点，选中后滚动并短暂高亮；「今天」没有记录时直接打开新建。
- 导出：阅读态「导出」下载单篇 .md；文件夹卡片菜单「导出全部」把整夹拼成一个 .md。

## Agent 工具

| 工具 | 作用 |
| --- | --- |
| `daily_review_folders()` | 文件夹列表：篇数、最近日期、本月天数、板块模板 |
| `daily_review_list({folder?, from?, to?, limit?})` | 条目摘要（日期/标题/首行/字数），不含全文 |
| `daily_review_read({folder, date, title?} \| {id})` | 一篇的全文与板块 |
| `daily_review_search({query, folder?, from?, to?})` | 全文检索，返回 ±30 字片段 |
| `daily_review_write({folder, date, title?, body, mode, id?, confirm?})` | `append`（默认）/ `create` / `overwrite`（必须显式传 `confirm: true` 且带 `id`） |

每次写入前先把旧文件复制进 `.daily-review/backups/`；写文件用「临时文件 + rename」原子替换；同名文件自动加序号，绝不覆盖。

## 安装

作为 bundle 装进 DSH profile：

```powershell
dsh plugin install <本仓库路径或链接>
```

安装后重启 DSH，侧边栏出现「日精进」入口；同时在「设置 → 插件 → 日精进」里可以改归档根目录。

## 开发与自检

```powershell
# 宿主层：数据、路由、工具、schema
node test-host.mjs
```

浏览器层的面板测试依赖一个 jsdom 环境，可自行搭一个最小 harness 挂载 `client.js` 导出的面板组件。

> 工具 `parameters` 必须是标准 JSON Schema：根节点 `type: 'object'`，必填写在根节点 `required: [...]`。写成属性级 `required: true` 会被宿主校验器拒绝，整轮请求都会被上游接口判为 `INVALID_REQUEST`。

## 约束

- 纯本地，不联网；Web 路由只接受本机回环访问。
- 不发云、不做多用户、不自动从外部服务抓取内容。
- 界面只用 `--dsw-alias-*` 主题 token，深浅色自动跟随。
